# Architecture (v0.1.0)

This file maps every block of the design diagram to the code that implements
it and to the test that checks it.

```
 host CPU ──AXI4-Lite──▶ axil_to_apb ─┐            PC ──USB-UART──▶ uart_apb_bridge (FPGA)
                                       ▼                                    │
                           apb_regfile (regs + doorbell, IRQ) ◀──────────────┘
   ┌───────────────┬───────────────┬──────────────┼──────────────┬──────────────┬─────────────┐
 SRAM PUF ─┐    OTP fuses        TRNG ─▶ HMAC-DRBG   weights ─DMA─▶ SHA-256      tamper mesh   HWCP boot ROM
 (sim/fuse)│    (OR-only, lock)  (90B health)  │     stream         │             + sensors     (banner+font)
           ▼                                   ▼                    ▼                │
        UDS ─▶ DICE CDI (HMAC) ─▶ key ladder (HMAC-DRBG) ─▶ key SRAM   PCR bank (extend-only, 16×256)
                    │  device_id                                      │
                    └──────────────────────┬───────────────────────────┘
                                           ▼
                   quote_engine: AIQ2 body (660 B) ─▶ SHA-256 ─▶ se_spi_master ─SPI─▶ secure element
                                           │                                     (ECDSA P-256 sign)
                                           ▼
                     quote ──▶ vendor CA chain ──▶ ai-id-verifier verify-hw / aiid cert verify
```

## Diagram block → file

| Diagram block | File(s) | Notes | Checked by |
|---|---|---|---|
| AXI register file / doorbell | `rtl/axil_to_apb.v`, `rtl/apb_regfile.v`, `fw/id_engine_regs.h` | AXI4-Lite → APB3, 43 registers, 32-bit STATUS, 4 IRQ sources (quote done, measurement done, zeroize, quote error), auto-increment multi-word registers | `tb/tb_axil_to_apb.sv`, `test/check_regmap.py`, `tb/tb_id_engine.cpp` |
| UART debug port (FPGA) | `rtl/uart_apb_bridge.v`, `tools/aiid_uart.py` | `W`/`R` byte protocol at 115200 8N1 | `tb/tb_uart_apb_bridge.sv` |
| SRAM PUF | `rtl/sram_puf.v` | `AI_ID_SIM_PUF`: public test UDS (simulation only). `AI_ID_FUSE_UDS`: UDS from OTP (FPGA). Neither: no UDS, engine fails closed. No real SRAM start-up PUF or fuzzy extractor is wired in. | `tb_id_engine` [6], [14] |
| OTP fuses | `rtl/otp_fuses.v` | 16×32-bit, OR-only programming, lock word 15, UDS words 5..12 read-protected, image survives reset; hw_rev/lifecycle/serial words | `tb_id_engine` [1], [2] |
| TRNG | `rtl/trng.v`, `fpga/ro_entropy_ecp5.v` | SP 800-90B RCT (cutoff 41) + APT (1024/840) on the raw bit; ECP5 ring oscillators on the board | `tb/tb_trng.sv`, `tb_id_engine` [8], [13] |
| HMAC-DRBG | `rtl/hmac_drbg.v` | SP 800-90A 10.1.2 over HMAC-SHA256 (22-byte provided-data limit), reseed every 64 generates | `tb/tb_hmac_drbg.sv` vs `test/gen_drbg_vectors.py` |
| DICE CDI | `rtl/dice_cdi.v`, `rtl/hmac_sha256.v` | CDI = HMAC(UDS, "DICE"‖label‖PCR); public device_id = HMAC(CDI, "DVID"‖label) | `tb_id_engine` [6] (OpenSSL HMAC) |
| Key ladder → key SRAM | `rtl/key_ladder.v` | DRBG seeded from CDI: slot 0 seal key, slot 1 ratcheting session key; keys never readable over APB | `tb_id_engine` [7], [14] |
| Seal / unseal | `rtl/seal_unit.v` | PCR-policy release; XOR wrap, not AES-GCM (see LIMITATIONS) | `tb_id_engine` [7] |
| Weights → SHA-256 | `rtl/sha256_stream.v`, `rtl/sha256_compress.v` | word-level streaming SHA-256 with hardware padding, fed by APB words or the 128-bit DMA port | `tb_id_engine` [4], [5] (real model weights with `+weights=`) |
| PCR extend-only bank | `rtl/pcr_bank.v` | 16 × SHA-256, extend only, no write path; measurement auto-extends PCR2; extends blocked while a quote is being signed | `tb_id_engine` [3], [5] |
| Attestation generator | `rtl/quote_engine.v` | AIQ2 body = "AIQ2"‖hw_rev‖lifecycle‖tamper‖counter‖time‖device_id‖nonce‖PCR0..15‖model‖config (660 B), hashed in RTL, fail-closed codes 1–5 | `tb_id_engine` [10], [11], [14] |
| ECDSA P-256 quote signer | `rtl/se_spi_master.v` + external secure element | Signing happens in an attached SE over SPI mode 0 (`0x01` GET_PUBKEY, `0x02` SIGN digest). The engine never holds the signing key. Simulation SE: `tb/se_model.h` (OpenSSL). | `tb_id_engine` [9]–[11], OpenSSL verify |
| Tamper mesh / sensors / zeroize | `rtl/tamper_mesh.v`, `rtl/tamper_ctrl.v` | LFSR pattern driven out and compared on return; any breach zeroizes UDS, CDI, device_id, key SRAM, seal, DRBG and raises an IRQ | `tb_id_engine` [12], [14] |
| Hardware code page (boot ROM) | `rtl/hwcp_rom.v` (generated by `tools/gen_hwcp_rom.py` from public-domain `tools/hwcp/font8x8_basic.h`) | CP437 printable half (0x20–0x7E) 8×8 glyphs + "AI-ID ENGINE v0.1.0 BOOT ROM" banner | `tb_id_engine` [0] |
| Vendor CA → verifier | `verifier/src/hw.rs` (`verify_hw`), `verifier/src/main.rs` (`verify-hw`), `hwid/src/ca.rs` | chain root→SE key, signature over SHA-256(body), nonce, freshness, tamper, lifecycle, hw_rev, device allow-list, model, config, PCR policy | `verifier` unit tests, `verifier/tests/rtl_fixture.rs` (quote produced by the RTL) |
| FPGA top | `fpga/ulx3s_top.v`, `fpga/ulx3s.lpf`, `fpga/Makefile` | ULX3S (LFE5U-85F): UART bridge, RO entropy, SE SPI pins, mesh pins, LEDs | `make -C fpga` (Yosys + nextpnr-ecp5 + ecppack) |

## Host software

| Piece | File(s) | What it does |
|---|---|---|
| `hwid show` | `hwid/src/hwid.rs` | Salted SHA-256 HWID from machine-id, DMI (sysfs, `dmidecode` fallback), CPU signature, disk serials, physical MACs (Linux); MachineGuid/CIM (Windows); IOPlatformUUID/serial (macOS). Prints the component list; raw values only with `--reveal`. Reads only — no spoofing. |
| `hwid challenge` / `license` | `hwid/src/license.rs`, `hwid/src/code.rs` | Offline activation: 10-byte challenge (version, product, HWID prefix) as `XXXX-XXXX-XXXX-XXXX-C` Crockford base32 with mod-37 check symbol; vendor answers with an Ed25519-signed response code (expiry day + features). |
| `hwid attest` | `hwid/src/attest.rs` | TPM 2.0 via tpm2-tools: EK, AK, AK↔EK MakeCredential/ActivateCredential, quote over PCR 0–7 with qualifying data SHA-256("AIID-TPM-V1"‖nonce‖HWID); TPMS_ATTEST parsed and verified natively. Simulated TPMs are flagged. Without a TPM: Ed25519 software fallback, clearly marked not hardware-backed. |
| `aiid cert create/verify/render` | `hwid/src/cert.rs`, `hwid/src/render.rs` | AI Birth Certificate: in-toto Statement v1 in a DSSE envelope (ECDSA P-256), weights streamed through SHA-256, architecture/checkpoint/instance/environment digest/HWID/attestation, optional embedded engine quote; verify checks signature, chain, freshness, subjects, re-hash, environment digest, attestation binding, engine quote + PCR2; SVG rendering. |
| `aiid ca` | `hwid/src/ca.rs` | TEST-ONLY demo vendor CA generated at run time. |
| `make demo` | `scripts/demo.sh` | RTL sim → quote → Rust verifier → cert create/verify on a real Hugging Face model. |
