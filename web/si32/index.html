    What is real, and what is modelled
    
  
    
    
    Logic
    Every logic operation is a two-input NAND evaluated each cycle. Constant inputs and duplicate gates are folded away during construction, as a synthesis tool would do.
    
    
    Storage
    The 1,024 flip-flops (31 registers × 32 bits plus the program counter) are simulated as clocked cells. Each one stands for a six-NAND edge-triggered flip-flop.
    
    
    Memory
    RAM, the framebuffer and the I/O ports sit off-chip on the bus as a behavioural model, the way a separate RAM chip would. The CPU drives address, data and byte-enable pins.
    
    
    Design
    Single-cycle: one instruction per clock. The adders are ripple-carry. There is no pipeline, cache, interrupts, CSRs, divide or MULH, and misaligned loads and stores are not supported.
    
    
    Verification
    An independent reference model executes the same program in lockstep, and the program counter is compared every cycle and all registers every 64 cycles. In this repository, web/si32/test/lockstep.test.js runs the same comparison headless in Node with every register checked after every instruction: the four demos (382,402 instructions) and 60 randomised programs (27,724 instructions, seed 1) match register for register and byte for byte in memory, and mutation.test.js shows that inverting any one of 300 randomly chosen gates is caught (297 of 300). It is a functional simulation in a web page, not a fabricated chip.
