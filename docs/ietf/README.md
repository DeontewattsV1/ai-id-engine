# IETF Internet-Draft sources

`draft-watts-rats-presilicon-evidence-00.xml` is an xml2rfc v3 source for an
individual Internet-Draft. It profiles the `aiid-evidence/v1` report
(docs/EVIDENCE.md) as an EAT (RFC 9711) profile for RATS (RFC 9334).

Render and check it locally:

```sh
pip install xml2rfc
xml2rfc --text --html draft-watts-rats-presilicon-evidence-00.xml
```

Submit the `.xml` file at https://datatracker.ietf.org/submit/. The
Datatracker renders it and runs idnits. An `-00` draft from a new author
needs confirmation by email before it is posted.
