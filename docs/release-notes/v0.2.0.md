# ai-id-engine v0.2.0: pre-silicon assessment, FPGA proxy

Prototype release. **Not production hardware, not silicon, not certified, and
nothing here is side-channel certified.** Demo keys and the CA are TEST-ONLY.
See `LIMITATIONS.md` in the tree.

## What's new
- **Masked Montgomery multipliers:** `mont_mul_masked_v2` (2 shares, four
  independent random ports) and `mont_mul_masked3` (3 shares), plus the
  `mont_mul_wrap` MASK_EN wrapper. All are checked against Python over the
  P-256 group order.
- **Gate-level TVLA** (`make tvla`): sky130_fd_sc_hd tt, Yosys
  `abc -liberty`, a capacitance-weighted toggle power model checked against
  Verilator waveforms, a null control and a positive control, first-order
  Welch and second-order centered-product tests, computed Bonferroni
  thresholds (4.37 at M=4000), and a single gate verdict.
  **Simulated traces.**
- **Coded fault detection** (`AI_ID_FAULT_DETECT`, off by default):
  - PCRs stored as SEC-DED (39,32) words;
  - Hamming(7,4) controller codes;
  - a duplicated sticky alarm that zeroizes and is cleared only by power-on;
  - a residue-checked `mont_mul_rc` (reference only).

  It detects faults. It is not side-channel hardening.
- **RTL→netlist equivalence** (`make equiv`): the `mont_mul` output,
  operand registers, FSM and `done` are proven. `t` and `bit_index` are an
  open proof gap, listed in `config/equiv_known.txt`.
- **Signed evidence reports** (`aiid evidence create|verify`, schema
  `aiid-evidence/v1`):
  - every field is classed identity, behavior or neither;
  - provenance is mandatory, and swtpm or the software key is always `software`;
  - the model digest, stimulus set and TVLA parameters are covered by the signature.
- **Reproducible bitstream** (`make -C fpga repro`): `REPRO=1` uses a fixed
  public test UDS. CI builds it twice and fails on any digest change against
  `fpga/repro.sha256` and `fpga/toolchain.lock`.
- **KATs:**
  - NIST SHA-256 multi-block, including 1M×'a';
  - HMAC RFC 4231 TC1–5;
  - ECDSA P-256 RFC 6979 on OpenSSL and Rust p256.
- **SymbiYosys proofs:**
  - OTP fuse semantics;
  - PCR extend-only;
  - fault alarm stickiness;
  - key-store FSM legality;
  - key non-interference: no key bit reaches status, zeroize or key_valid.
- **Verifier:** ADR-0003 replay-safe tickets.
- **Si-32:** a gate-level RV32I page at `/si32/`.
- **Bundle review:** adopt, fix or reject for all 84 bundle files. The
  bundle's in-fabric ECDSA was rejected because it leaks the key, so quotes
  stay SE/TPM-signed.

## TVLA (CI profile: 4000 traces/group, M=4000, alpha=0.05; simulated)

| | masked_v2 (2-share) | masked3 (3-share) |
|---|---|---|
| null control (crit 4.37) | 3.24 ok | see the evidence tarball |
| positive control, plain mont_mul | 82.96 detected | 82.96 detected |
| 1st order \|t\|max | 3.15 | ≈4.2 |
| 2nd order \|t\|max (crit 4.46) | **26.50, leaks** | ≈3.5 |
| area vs plain (79,764 µm²) | 2.29× | ≈3.2× |
| latency vs plain (258 cycles) | 1042 | 2343 |
| gate | exit 2: use 3 shares | exit 0: pass **at this trace count** |

- The masked3 column comes from the handoff run (4.22 and 3.47).
- This release's own numbers for both designs are in
  `tvla-evidence-v0.2.0.tar.gz`, with signed `evidence.json` reports. Those
  reports have a software root.
- 4000 traces/group resolves leaks above about 0.1σ. The 1M-trace
  `PROFILE=signoff` run has not been done.

## Fault injection (simulation)

| Target | Single-bit upsets | Double-bit upsets |
|---|---|---|
| SEC-DED words (64-word exhaustive) | 2496/2496 corrected | 47424/47424 detected |
| PCR bank words | 4992/4992 corrected | 5289/5289 detected |

- PCR controller states: 56/56 one- and two-bit upsets detected and latched.
- `mont_mul_rc`: 307 of 307 effective upsets detected, and 0 false alarms in 40 clean runs.
- Full chip with the define on: 192 checks pass, and the alarm is never set.

1. Run `sha256sum -c SHA256SUMS`.
2. Run `./aiid-linux-x86_64 evidence verify --report <dir>/evidence.json`. It reports the provenance root as `software`.

## Limitations (short version; see LIMITATIONS.md)
- No silicon, no board bring-up for this release, and no side-channel or fault-injection certification.
- TVLA uses zero-delay simulated traces: no glitches, coupling, IR drop or EM.
- Second order is validated by synthetic tests only.
- Fault detection is opt-in and covers PCR storage and its controller only.
- Equivalence is partial (see above).
- Evidence provenance is host-reported. It is AK-signed, but not checked against an EK certificate chain.
- In CI, the TPM path runs against swtpm and is reported as `software`.
