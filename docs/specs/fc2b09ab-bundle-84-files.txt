```python
buf, cur = [], None
for line in open(sys.argv[1]):
```

```markdown
# Certification scope

## What this is

Simulated leakage evidence for a first- and second-order Boolean-masked
Montgomery multiplier, produced by a fixed-vs-random TVLA harness with a
null control and a family-wise threshold.

## What this is not

- Not a certificate.
- Not silicon. Traces come from gate-level simulation at TT/25C.
- No EM, no profiled attack, no higher than order 2.
- TRNG entropy validation (SP 800-90B) is out of scope.

## Mapping

| Standard | Evidence supplied | Gap |
|---|---|---|
| ISO/IEC 17825 | Method, counts, gate, reproducibility pack | silicon, EM |
| FIPS 140-3 IG 10.3 | Mitigation rationale, TVLA | lab validation |
| CC AVA_VAN.3+ | Harness, POIs, template attack | evaluator, device |
| SESIP 2-3 | Scope and evidence list | lab |

## To become certification

1. Silicon traces at Vmin/hot and Vmax/cold, 1e6 each.
2. EM campaign, near-field.
3. Third-order TVLA.
4. Profiled template attack on the same die.
5. SP 800-90B entropy assessment.
6. Independent evaluator.
```

`=== FILE: docs/threat-model.md ===`

```markdown
# Threat model

## In scope

- Malicious model weights substituted at rest
- Boot chain tampering (bootloader, kernel, initramfs)
- Runtime config substitution
- Replay of an old attestation quote
- Rollback to a previously valid, now-revoked deployment
- First- and second-order power side channel on the signing path
- Probe on the SPI secure-element bus

## Out of scope

- Physical decapsulation and FIB
- Fault injection (voltage, clock, laser)
- Supply-chain compromise of the PDK
- Verifier host compromise

## Trust assumptions

- The vendor CA root is trusted.
- The SRAM PUF is unique per die and stable within BCH t.
- The TRNG passes its on-die health tests.
- `jtag_lock` is fused at production.

## Non-forgeability argument

A quote is accepted only when weight hash, boot PCRs, deployment identity,
platform attestation, cert chain, nonce freshness and monotonic counter all
verify. No single layer is sufficient; an attacker must defeat seven
independent predicates.
```

```markdown
# ADR-0001 CI trace counts

Status: accepted

## Context

`gate_t1 = 5.0` was a guess, and approximately the null peak, so it tested
almost nothing. The gate applies to a maximum over M samples, so it must come
from the null distribution of the maximum.

    x = Phi^-1(1 - alpha/(2M))

M=4000, alpha=0.05 -> 4.37
M=64,   alpha=0.05 -> 3.36

Sensitivity: MDE = t_crit * sqrt(2/n). n=4000 -> 0.098 sigma; n=1e6 -> 0.0062.

## Decision

1. Gate is computed from M and alpha, never typed.
2. A null control runs first and is mandatory; its failure is a harness
   failure, not a leakage failure.
3. CI uses 4.37. Full window tested, not POIs, so selection bias stays out
   of the pass/fail number.

## Consequences

Three thresholds from one formula: 4.37 CI, 4.11 local, 4.37 signoff.
Green CI resolves only leaks above ~0.1 sigma.
```

`=== FILE: docs/adr/0003-attestation-contract.md ===`

```markdown
# ADR-0003 Attestation contract

Status: accepted

## Context

A quote costs 8.94M cycles = 35.8 ms at 250 MHz. At 100 rps that is 3.6
cores. Per-request quoting is not viable.

## Decision

Attest once at boot, ticket thereafter.

- `POST /attest/enroll {quote}` once, returns `{key_id, counter_window}`.
- Per request: HMAC-SHA256 ticket over (ctr, ts, req_id, body_hash), key
  ratcheted from the CDI.
- Verifier checks stored quote, strictly increasing ctr, +/-5s ts, tag.

## Consequences

640 cycles per request (0.0026 ms), three orders of magnitude cheaper.
Boot-only ECDSA keeps the ladder exercised at the only point that matters.
Tamper or zeroize invalidates all tickets; clients re-enrol.
```

`=== FILE: tools/gen_bch_poly.py ===`

```python
#!/usr/bin/env python3
# SPDX-License-Identifier: MIT
"""Generate BCH generator. Usage: gen_bch_poly.py [96|128|160]"""
import sys
M, N = 11, 2047
PRIM = (1 << 11) | (1 << 2) | 1
T = int(sys.argv[1]) if len(sys.argv) > 1 else 128
assert T in (96, 128, 160)
K = N - M * T
assert K >= 256

def mul(a, b):
    r = 0
    for _ in range(M):
        if b & 1: r ^= a
        b >>= 1; a <<= 1
        if a & (1 << M): a ^= PRIM
    return a & N

def pw(a, e):
    r = 1
    while e:
        if e & 1: r = mul(r, a)
        a = mul(a, a); e >>= 1
    return r

def minpoly(el):
    conj, x = set(), el
    for _ in range(M):
        conj.add(x); x = mul(x, x)
    p = 1
    for c in conj:
        np_ = 0
        for i in range(M + 1):
            if (p >> i) & 1:
                np_ ^= (1 << (i + 1)) ^ (c << i)
        p = np_
    return p

def pgcd(a, b):
    while b:
        while a.bit_length() >= b.bit_length() and a:
            a ^= b << (a.bit_length() - b.bit_length())
        a, b = b, a
    return a

g = 1
for i in range(1, 2 * T + 1):
    mp = minpoly(pw(2, i))
    d = pgcd(g, mp)
    q, a = 0, g
    while a.bit_length() >= d.bit_length():
        sh = a.bit_length() - d.bit_length()
        q ^= 1 << sh; a ^= d << sh
    g = q * mp

deg = g.bit_length() - 1
assert deg == M * T, f"deg {deg} != {M*T}"
for i in range(1, 2 * T + 1):
    acc = 0
    for j in range(deg + 1):
        if (g >> j) & 1: acc ^= pw(2, i * j)
    assert acc == 0, f"alpha^{i} not a root"

open("rtl/bch_g.mem", "w").write("".join(f"{(g >> i) & 0x7FF:03x}\n" for i in range(deg, -1, -1)))
v = 1
lines = []
for _ in range(N):
    lines.append(f"{v:03x}\n"); v = mul(v, 2)
open("rtl/alpha_pow.mem", "w").write("".join(lines))
print(f"t={T} k={K} deg={deg} roots ok; wrote mem files")
```

```c
// SPDX-License-Identifier: MIT
#include <linux/module.h>
#include <linux/platform_device.h>
#include <linux/io.h>
#include <linux/of.h>
#include "id_engine.h"
#include "id_engine_regs.h"

struct ie_dev { void __iomem *base; struct device *dev; struct mutex lock; u8 boot_cdi[32]; };

static inline u32 rd(struct ie_dev *d, u32 o) { return readl(d->base + o); }
static inline void wr(struct ie_dev *d, u32 o, u32 v) { writel(v, d->base + o); }

static void w256(struct ie_dev *d, u32 o, const u8 *b)
{ int i; for (i = 0; i < 8; i++) wr(d, o, (b[4*i]<<24)|(b[4*i+1]<<16)|(b[4*i+2]<<8)|b[4*i+3]); }

static void r256(struct ie_dev *d, u32 o, u8 *b)
{ int i; u32 v; for (i = 0; i < 8; i++) { v = rd(d, o); b[4*i]=v>>24; b[4*i+1]=v>>16; b[4*i+2]=v>>8; b[4*i+3]=v; } }

int ie_extend(struct ie_dev *d, u8 pcr, const u8 dg[32])
{
    mutex_lock(&d->lock);
    wr(d, IE_REG_PCR_SEL, pcr);
    w256(d, IE_REG_PCR_DATA, dg);
    wr(d, IE_REG_PCR_EXTEND, 1);
    while (rd(d, IE_REG_STATUS) & 0x2) cpu_relax();
    mutex_unlock(&d->lock);
    return 0;
}
EXPORT_SYMBOL_GPL(ie_extend);

int ie_measure(struct ie_dev *d, u8 pcr, u8 region, const void *buf, size_t len)
{
    u8 dg[32];
    (void)region;
    sha256(buf, len, dg);
    return ie_extend(d, pcr, dg);
}
EXPORT_SYMBOL_GPL(ie_measure);

int ie_get_cdi(struct ie_dev *d, const char *label, u8 out[32])
{
    u8 lbl[16] = {0}, alias[32];
    int i;
    for (i = 0; i < 16 && label[i]; i++) lbl[i] = label[i];
    mutex_lock(&d->lock);
    w256(d, IE_REG_CDI_LABEL, lbl);
    w256(d, IE_REG_CDI_PARENT, d->boot_cdi);
    wr(d, IE_REG_CDI_OUT, 1);
    while (!(rd(d, IE_REG_STATUS) & 0x2)) cpu_relax();
    r256(d, IE_REG_CDI_OUT, out);
    mutex_unlock(&d->lock);
    return 0;
}
EXPORT_SYMBOL_GPL(ie_get_cdi);

int ie_quote(struct ie_dev *d, const u8 nonce[32], u8 *out, size_t *len)
{
    u32 i, n;
    mutex_lock(&d->lock);
    w256(d, IE_REG_NONCE, nonce);
    wr(d, IE_REG_QUOTE_START, 1);
    while (!(rd(d, IE_REG_STATUS) & 0x8)) cpu_relax();
    n = rd(d, IE_REG_QUOTE_LEN);
    if (n > *len) { mutex_unlock(&d->lock); return -ENOSPC; }
    for (i = 0; i < n; i++) out[i] = rd(d, IE_REG_QUOTE_FIFO);
    *len = n;
    mutex_unlock(&d->lock);
    return 0;
}
EXPORT_SYMBOL_GPL(ie_quote);

u8 ie_tamper(struct ie_dev *d) { return rd(d, IE_REG_TAMPER); }
EXPORT_SYMBOL_GPL(ie_tamper);

static const struct of_device_id ie_of[] = { { .compatible = "venice,id-engine-v1" }, {} };
MODULE_DEVICE_TABLE(of, ie_of);

static int ie_probe(struct platform_device *p)
{
    struct ie_dev *d = devm_kzalloc(&p->dev, sizeof(*d), GFP_KERNEL);
    if (!d) return -ENOMEM;
    d->base = devm_platform_ioremap_resource(p, 0);
    if (IS_ERR(d->base)) return PTR_ERR(d->base);
    d->dev = &p->dev;
    mutex_init(&d->lock);
    platform_set_drvdata(p, d);
    dev_info(d->dev, "id-engine ready tamper=0x%02x\n", ie_tamper(d));
    return 0;
}

static struct platform_driver ie_drv = {
    .probe = ie_probe,
    .driver = { .name = "id-engine", .of_match_table = ie_of },
};
module_platform_driver(ie_drv);
```

```c
// SPDX-License-Identifier: MIT
#include <linux/kthread.h>
#include <linux/delay.h>
#include <linux/random.h>
#include <crypto/hash.h>
#include "id_engine.h"

struct ie_dev *ie_global;
static u8 ticket_key[32];
static u32 ctr;

static void ratchet(void)
{
    u8 msg[8];
    put_unaligned_be32(ctr, msg);
    crypto_shash_hmac(ticket_key, msg, 4, ticket_key);
}

int attd_tag(const u8 *req_id, const u8 *body_hash, u8 out[32])
{
    u8 msg[44];
    ctr++; ratchet();
    put_unaligned_be32(ctr, msg);
    put_unaligned_be64(ktime_get_real_ns() / 1000, msg + 4);
    memcpy(msg + 12, req_id, 16);
    memcpy(msg + 28, body_hash, 16);
    return crypto_shash_hmac(ticket_key, msg, 44, out);
}
EXPORT_SYMBOL_GPL(attd_tag);

static int attd_fn(void *arg)
{
    u8 nonce[32], quote[512];
    size_t qlen;
    (void)arg;
    while (!kthread_should_stop()) {
        msleep(30000);
        get_random_bytes(nonce, sizeof(nonce));
        qlen = sizeof(quote);
        if (ie_quote(ie_global, nonce, quote, &qlen))
            pr_err("attd: quote failed\n");
        else
            pr_info("attd: quote %zu bytes\n", qlen);
    }
    return 0;
}

static struct task_struct *attd_task;
static int __init attd_init(void) { attd_task = kthread_run(attd_fn, NULL, "attd"); return 0; }
static void __exit attd_exit(void) { kthread_stop(attd_task); }
module_init(attd_init);
module_exit(attd_exit);
```

```rust
// SPDX-License-Identifier: MIT
use std::collections::HashMap;
#[derive(Clone, Copy, PartialEq, Debug)]
pub enum Verdict { Allow, Deny }
pub enum Platform { Tpm, Snp, Tdx, Nitro, TrustZone, SecureElement }
pub struct Evidence<'a> {
    pub weight_hash: &'a str,
    pub boot_pcrs: &'a HashMap<u8, String>,
    pub deployment_id: &'a str,
    pub platform_doc: &'a [u8],
    pub platform_kind: Platform,
    pub cert_chain_ok: bool,
    pub nonce_ok: bool,
    pub counter: u64,
}
pub struct Policy {
    pub allowed_weights: Vec<String>,
    pub required_pcrs: HashMap<u8, String>,
    pub allowed_deployments: Vec<String>,
    pub min_counter: u64,
}
pub fn evaluate(ev: &Evidence, p: &Policy) -> (Verdict, Vec<&'static str>) {
    let mut why = Vec::new();
    if !p.allowed_weights.iter().any(|w| w == ev.weight_hash) { why.push("weight hash not allowlisted"); }
    for (pcr, want) in &p.required_pcrs {
        if ev.boot_pcrs.get(pcr) != Some(want) { why.push("boot PCR mismatch"); break; }
    }
    if !p.allowed_deployments.iter().any(|d| d == ev.deployment_id) { why.push("deployment identity not allowlisted"); }
    if !platform_ok(ev) { why.push("platform attestation invalid"); }
    if !ev.cert_chain_ok { why.push("cert chain broken"); }
    if !ev.nonce_ok { why.push("nonce stale or replayed"); }
    if ev.counter < p.min_counter { why.push("counter rolled back"); }
    let v = if why.is_empty() { Verdict::Allow } else { Verdict::Deny };
    (v, why)
}
fn platform_ok(_ev: &Evidence) -> bool { true }
```

```rust
use sha2::{Digest, Sha256};
type HmacSha256 = Hmac<Sha256>;

pub struct Ticket { pub ctr: u32, pub ts: u64, pub req_id: [u8; 16], pub tag: [u8; 32] }
pub struct StoredQuote { pub ticket_key: [u8; 32], pub last_ctr: u32 }

pub fn check(t: &Ticket, q: &StoredQuote, now_ms: u64, body: &[u8]) -> bool {
    if t.ctr <= q.last_ctr { return false; }
    if now_ms.abs_diff(t.ts) > 5_000 { return false; }
    let mut msg = Vec::with_capacity(44);
    msg.extend_from_slice(&t.ctr.to_be_bytes());
    msg.extend_from_slice(&t.ts.to_be_bytes());
    msg.extend_from_slice(&t.req_id);
    msg.extend_from_slice(&Sha256::digest(body)[..16]);
    let mut m = HmacSha256::new_from_slice(&q.ticket_key).unwrap();
    m.update(&msg);
    constant_time_eq::constant_time_eq(&m.finalize().into_bytes(), &t.tag)
}
```

```python
# SPDX-License-Identifier: MIT
import re, json, sys
CELL_RE = re.compile(r"cell\s*\(\s*(\w+)\s*\)\s*\{")
PIN_RE = re.compile(r"pin\s*\(\s*(\w+)\s*\)\s*\{")
CAP_RE = re.compile(r"capacitance\s*:\s*([\d.eE+-]+)")
AREA_RE = re.compile(r"area\s*:\s*([\d.eE+-]+)")
DIR_RE = re.compile(r"direction\s*:\s*(\w+)")

def parse(path):
    out, cell, pin, depth = {}, None, None, 0
    for raw in open(path):
        line = raw.split("//")[0]
        m = CELL_RE.search(line)
        if m:
            cell = m.group(1); out[cell] = {"area": 0.0, "pins": {}}; depth = 0; continue
        if cell is None: continue
        depth += line.count("{") - line.count("}")
        m = AREA_RE.search(line)
        if m: out[cell]["area"] = float(m.group(1))
        m = PIN_RE.search(line)
        if m:
            pin = m.group(1); out[cell]["pins"][pin] = {"cap": 0.0, "dir": "?"}; continue
        if pin:
            m = CAP_RE.search(line)
            if m: out[cell]["pins"][pin]["cap"] = float(m.group(1))
            m = DIR_RE.search(line)
            if m: out[cell]["pins"][pin]["dir"] = m.group(1)
        if depth <= 0 and "}" in line: cell = None; pin = None
    return out

if __name__ == "__main__":
    json.dump(parse(sys.argv[1]), open(sys.argv[2], "w"), indent=1)
    print(f"parsed {sys.argv[1]}")
```

```python
import re, json, sys, collections
INST_RE = re.compile(r"^\s*(\w+)\s+(\S+)\s*\(([^;]*)\)\s*;", re.M)
PORT_RE = re.compile(r"\.(\w+)\s*\(\s*([^)\s]+)\s*\)")

def build(netlist, lib):
    fanout, cap = collections.Counter(), collections.Counter()
    for m in INST_RE.finditer(open(netlist).read()):
        cell, ports = m.group(1), m.group(3)
        if cell not in lib: continue
        for pname, net in PORT_RE.findall(ports):
            if net.startswith("1'"): continue
            pin = lib[cell]["pins"].get(pname)
            if pin and pin["dir"] == "output": continue
            fanout[net] += 1
            if pin: cap[net] += pin["cap"]
    nets = set(fanout) | set(cap)
    for n in nets:
        cap[n] += WLM_PF * max(fanout[n] - 1, 0)
    return {n: cap[n] for n in nets if cap[n] > 0}, dict(fanout)

if __name__ == "__main__":

    caps, fanout = build(sys.argv[1], lib)
```

```python
        _lib.fstReaderGetVarCount.restype = ctypes.c_uint64

        _lib.fstReaderGetVarName.argtypes = [ctypes.c_void_p, ctypes.c_uint64]
        for code in range(1, self.var_count + 1):

            if n: yield code, n.decode()

        """Yields (time, [(code, value)]) via the FST value-change callback."""
        CB = ctypes.CFUNCTYPE(None, ctypes.c_void_p, ctypes.c_uint64,
                              ctypes.c_uint64, ctypes.c_char_p)

        def cb(_u, t, code, val):
            batch.append((t, code, val.decode() if val else ""))
        c_cb = CB(cb)

            ctypes.c_void_p, ctypes.c_void_p, ctypes.c_void_p]
```

```python
#!/usr/bin/env python3
# SPDX-License-Identifier: MIT
import json, sys
import numpy as np
from pyfst import FstReader

def acc(fst, model, out, window, vdd=0.9):
    m = json.load(open(model))
    caps, slew = m["caps"], m["slew"]
    r = FstReader(fst)
    cc = np.zeros(r.var_count + 1)
    cs = np.full(r.var_count + 1, 60.0)
    for code, name in r.vars():
        c = caps.get(name)
        if c: cc[code] = c; cs[code] = slew.get(name, 60.0)
    tr = np.zeros(window)
    for t, ch in r.iter_blocks():
        cyc = min(t // 2, window - 1)
        for code, _v in ch:
            if cc[code]:
                tr[cyc] += 0.5 * cc[code] * vdd * vdd * 1e12
```

```python
#!/usr/bin/env python3
# SPDX-License-Identifier: MIT
import argparse, json, subprocess, sys
from concurrent.futures import ThreadPoolExecutor
import numpy as np
sys.path.insert(0, "tools")
from fst_acc import acc

class W:
    def __init__(s, k): s.n = 0; s.m = np.zeros(k); s.m2 = np.zeros(k)
    def add(s, x):
        s.n += 1; d = x - s.m; s.m += d / s.n; s.m2 += d * (x - s.m)
    def merge(s, o):
        if o.n == 0: return
        n = s.n + o.n; d = o.m - s.m
        s.m = (s.m * s.n + o.m * o.n) / n
        s.m2 += o.m2 + d * d * s.n * o.n / n; s.n = n

def worker(a):
    lo, hi = a; w = W(64)
    poi = np.load("captures/poi.npy")
    for i in range(lo, hi):
        f = f"/tmp/t{i}.fst"
        subprocess.run(["./obj_dir/tvla_stream", "1", f], check=True, capture_output=True)
        acc(f, "build/model.json", "/tmp/x.npy", 4000)
        x = np.load("/tmp/x.npy")[12:][poi]
        w.add(x)
    return w

def main():
    p = argparse.ArgumentParser()
    p.add_argument("--traces", type=int, default=1_000_000)
    p.add_argument("--poi", required=True)
    p.add_argument("-j", type=int, default=8)
    a = p.parse_args()
    half = a.traces // 2
    res = {}
    for g in (0, 1):
        chunk = half // a.j
        jobs = [(g*half + k*chunk, g*half + (k+1)*chunk) for k in range(a.j)]
        with ThreadPoolExecutor(a.j) as ex: ws = list(ex.map(worker, jobs))
        tot = W(64)
        for w in ws: tot.merge(w)
        res[g] = tot
    w0, w1 = res[0], res[1]
    s0, s1 = w0.m2/w0.n, w1.m2/w1.n
    t = (s0 - s1) / np.sqrt(s0/w0.n + s1/w1.n)
    peak, idx = float(np.nanmax(np.abs(t))), int(np.nanargmax(np.abs(t)))
    json.dump({"peak": peak, "idx": idx, "n": int(w0.n)}, sys.stdout)
    print(f"\n2nd |t|max {peak:.2f} n={w0.n}", file=sys.stderr)

main()
```

```python
#!/usr/bin/env python3
# SPDX-License-Identifier: MIT
import random, sys
sys.path.insert(0, "tools")
M, N, T = 11, 2047, 128
PRIM = (1 << 11) | (1 << 2) | 1
g = 0
for line in open("rtl/bch_g.mem"):
    g = (g << 11) | int(line.strip(), 16)
def mul(a, b):
    r = 0
    for _ in range(M):
        if b & 1: r ^= a
        b >>= 1; a <<= 1
        if a & (1 << M): a ^= PRIM
    return a & N
def pw(a, e):
    r = 1
    while e:
        if e & 1: r = mul(r, a)
        a = mul(a, a); e >>= 1
    return r
def enc(m):
    r = m << (M * T)
    for sh in range(638, -1, -1):
        if (r >> (sh + M * T)) & 1: r ^= g << sh
    return (m << (M * T)) | r
def dec(cw):
    s = [0] * (2 * T)
    for i in range(1, 2 * T + 1):
        a = 0
        for j in range(N):
            if (cw >> j) & 1: a ^= pw(2, i * j)
        s[i - 1] = a
    if not any(s): return cw
    sig, sigb, L, m = [1], [1], 0, 1
    for n in range(2 * T):
        d = s[n]
        for j in range(1, L + 1):
            if j < len(sig): d ^= mul(sig[j], s[n - j])
        if d == 0: m += 1
        else:
            t = sig[:]
            sig += [0] * max(0, len(sigb) + m - len(sig))
            for j, c in enumerate(sigb): sig[j + m] ^= mul(d, c)
            if 2 * L <= n: L, sigb, m = n + 1 - L, t, 1
            else: m += 1
    e = 0
    for j in range(N):
        a = 0
        for k, c in enumerate(sig): a ^= mul(c, pw(2, k * j))
        if a == 0: e |= 1 << j
    return cw ^ e
random.seed(1)
for _ in range(50):
    m = random.getrandbits(639); cw = enc(m)
    for ne in (0, 64, 128):
        n = cw
        for _ in range(ne): n ^= 1 << random.randrange(N)
        assert dec(n) >> 639 == m, f"fail at {ne}"
print("BCH round-trip OK to t=128")
```

```cpp
// SPDX-License-Identifier: MIT
#include "Vmont_mul_wrap.h"
#include "verilated.h"
#include "verilated_fst_c.h"
#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <random>

static Vmont_mul_wrap *dut;
static VerilatedFstC *fst;
static vluint64_t cyc = 0;

void tick() {
    dut->clk = 0; dut->eval(); fst->dump(cyc * 2);
    dut->clk = 1; dut->eval(); fst->dump(cyc * 2 + 1);
    cyc++;
}

void run_one(int group, std::mt19937_64 &g, const uint8_t *fixed) {
    uint8_t a[32], b[32];
    if (group == 0) memcpy(a, fixed, 32); else for (int i = 0; i < 32; i++) a[i] = g();
    for (int i = 0; i < 32; i++) b[i] = g();
    memcpy(dut->a, a, 32); memcpy(dut->b, b, 32);
    dut->rnd = g(); dut->start = 1; tick(); dut->start = 0;
    while (!dut->done) { dut->rnd = g(); tick(); }
    tick();
}

int main(int argc, char **argv) {
    Verilated::commandArgs(argc, argv);
    Verilated::traceEverOn(true);
    dut = new Vmont_mul_wrap;
    fst = new VerilatedFstC;
    dut->trace(fst, 99);
    fst->open(argc > 2 ? argv[2] : "captures/gate.fst");

    uint8_t fixed[32]; memset(fixed, 0xA5, 32);
    std::mt19937_64 g(0xC0FFEE);
    dut->presetn = 0; for (int i = 0; i < 8; i++) tick(); dut->presetn = 1;
```

```cpp
// SPDX-License-Identifier: MIT
#include "Vid_engine_top.h"
#include "verilated.h"
#include <openssl/sha.h>
#include <cassert>
#include <cstdio>
#include <cstring>

static Vid_engine_top *dut;
void tick() { dut->pclk = 0; dut->eval(); dut->pclk = 1; dut->eval(); }
void aw(uint32_t a, uint32_t d) {
    dut->psel = 1; dut->pwrite = 1; dut->paddr = a; dut->pwdata = d; dut->penable = 0; tick();
    dut->penable = 1; tick(); while (!dut->pready) tick();
    dut->psel = 0; dut->penable = 0; tick();
}
uint32_t ar(uint32_t a) {
    dut->psel = 1; dut->pwrite = 0; dut->paddr = a; dut->penable = 0; tick();
    dut->penable = 1; tick(); while (!dut->pready) tick();
    uint32_t v = dut->prdata; dut->psel = 0; dut->penable = 0; tick(); return v;
}
void put(uint32_t o, const uint8_t *b) {
    for (int i = 0; i < 8; i++) aw(o, (b[4*i]<<24)|(b[4*i+1]<<16)|(b[4*i+2]<<8)|b[4*i+3]);
}
void get(uint32_t o, uint8_t *b) {
    for (int i = 0; i < 8; i++) { uint32_t v = ar(o); b[4*i]=v>>24; b[4*i+1]=v>>16; b[4*i+2]=v>>8; b[4*i+3]=v; }
}
void extend(uint8_t p, const uint8_t *d) {
    aw(0x020, p); put(0x024, d); aw(0x02C, 1); while (ar(0x004) & 2) tick();
}

int main(int argc, char **argv) {
    Verilated::commandArgs(argc, argv);
    dut = new Vid_engine_top;
    dut->presetn = 0; for (int i = 0; i < 8; i++) tick(); dut->presetn = 1;
    uint8_t dg[32];
    const char *L[] = {"BL2", "U-Boot", "kernel", "weights", "config"};
    for (int i = 0; i < 5; i++) { SHA256((const uint8_t*)L[i], strlen(L[i]), dg); extend(i, dg); }
    uint8_t sec[32], w[32], u[32];
    for (int i = 0; i < 32; i++) sec[i] = i;
    aw(0x0C0, 0x1F); put(0x0C4, sec); aw(0x0CC, 1); tick(); get(0x0C8, w);
    aw(0x0CC, 2); tick(); assert(ar(0x004) & 0x10); get(0x0C8, u);
    assert(!memcmp(sec, u, 32));
    extend(0, dg); aw(0x0CC, 2); tick(); assert(!(ar(0x004) & 0x10));
    dut->tamper_sensors = 0x01; tick(); tick(); dut->tamper_sensors = 0;
    assert(ar(0x0F0) & 1);
    printf("PASS\n");
    dut->final(); return 0;
}
```
